# BCD to Excess-3 Code Converter in Verilog

## Overview

This project implements a **BCD to Excess-3 Code Converter** using Verilog HDL. The module converts a 4-bit **Binary-Coded Decimal (BCD)** input into its corresponding **Excess-3 code** representation.

Excess-3 is a non-weighted decimal code that is generated by adding **3 (0011)** to each BCD digit. It is commonly used in digital arithmetic circuits because it provides useful properties such as self-complementing behavior.

The design is implemented using **behavioral modeling** with a `case` statement to map each valid BCD input value to its corresponding Excess-3 output.

## Features

- Converts 4-bit BCD input into Excess-3 code
- Supports decimal values from 0 to 9
- Uses behavioral Verilog modeling
- Implements combinational logic design
- No clock or sequential elements required
- Fully synthesizable for FPGA and ASIC implementations

## Module Description

### BCD to Excess-3 Converter (`BCD2excess3`)

The module accepts a 4-bit BCD input and produces the corresponding 4-bit Excess-3 output.

The conversion formula is:

```
Excess-3 Code = BCD + 0011
```

Example:

```
BCD = 0101 (Decimal 5)

0101
+0011
-----
1000

Excess-3 = 1000
```

## Inputs and Output

### Input

| Signal | Width | Description |
|--------|------:|-------------|
| `bcd_in` | 4 bits | BCD input value (0-9) |

### Output

| Signal | Width | Description |
|--------|------:|-------------|
| `excess3_out` | 4 bits | Corresponding Excess-3 code |

## How It Works

The module uses a lookup table implemented using a `case` statement:

```verilog
always@(bcd_in)
begin
    case(bcd_in)
```

Each valid BCD input is mapped to its Excess-3 equivalent.

Example:

```verilog
4'b0011 : excess3_out = 4'b0110;
```

Here:

```
BCD value = 3

3 + 3 = 6

BCD      = 0011
Excess-3  = 0110
```

For invalid BCD inputs (`1010` to `1111`), the output is assigned as unknown:

```verilog
default : excess3_out = 4'bxxxx;
```
