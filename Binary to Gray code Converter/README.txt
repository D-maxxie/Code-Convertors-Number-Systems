# 4-Bit Binary to Gray Code Converter in Verilog

## Overview

This project implements a **4-bit Binary to Gray Code Converter** using Verilog HDL. The purpose of this circuit is to convert a binary number into its equivalent Gray code representation.

Gray code is a binary numeral system in which two consecutive values differ by only one bit. It is widely used in digital systems where minimizing transition errors between states is important.

The design is implemented using **gate-level modeling**, using basic logic gates such as **Buffer** and **XOR gates** to perform the conversion.

## Features

- Converts 4-bit binary input into 4-bit Gray code output
- Uses gate-level Verilog modeling
- Implements conversion using XOR logic
- Pure combinational circuit design
- No clock or sequential elements required
- Fully synthesizable for FPGA and ASIC implementations

## Module Description

### Binary to Gray Converter (`binary2gray`)

The module accepts a 4-bit binary input and produces the corresponding 4-bit Gray code output.

The conversion follows the Gray code generation rule:

```
Gray[3] = Binary[3]

Gray[2] = Binary[3] XOR Binary[2]

Gray[1] = Binary[2] XOR Binary[1]

Gray[0] = Binary[1] XOR Binary[0]
```

## Inputs and Output

### Input

| Signal | Width | Description |
|--------|------:|-------------|
| `binary_in` | 4 bits | 4-bit binary input value |

### Output

| Signal | Width | Description |
|--------|------:|-------------|
| `gray_out` | 4 bits | Corresponding Gray code output |

## How It Works

The most significant bit of Gray code is directly copied from the binary input:

```verilog
buf buf1(gray_out[3], binary_in[3]);
```

The remaining Gray code bits are generated using XOR operations:

```verilog
xor xor1(gray_out[2], binary_in[3], binary_in[2]);

xor xor2(gray_out[1], binary_in[2], binary_in[1]);

xor xor3(gray_out[0], binary_in[1], binary_in[0]);
```

Each Gray code bit is generated by XORing adjacent binary bits.

## Conversion Example

Example:

```
Binary Input : 1010
```

Conversion:

```
Gray[3] = 1

Gray[2] = 1 XOR 0 = 1

Gray[1] = 0 XOR 1 = 1

Gray[0] = 1 XOR 0 = 1
```

Output:

```
Gray Code = 1111
```
